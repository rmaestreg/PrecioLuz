# Precio Luz — publicación en GitHub Pages

Sube **todo el contenido de esta carpeta** a la raíz del repositorio:

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- carpeta `icons/`

Después activa GitHub Pages desde `Settings → Pages → Deploy from a branch → main / (root)`.

En iPhone/iPad: Safari → Compartir → Añadir a pantalla de inicio.
En Android: Chrome → menú ⋮ → Añadir a pantalla de inicio / Instalar aplicación.
